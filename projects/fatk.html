FATK

Feature-Adaptive Triple Kernel: learning which features matter and how similarity should be measured for each one.

Final Year Project at the American University of Beirut · Kernel Learning / Interpretable Machine Learning

My contribution: theoretical construction of the model and design/evaluation of the synthetic-data experiments.

Recipient of AUB MSFEA’s Dean’s Award for Creative Achievement.

Motivation

Standard kernels usually compress all feature differences into one global similarity measure. That can be limiting when different dimensions carry different amounts of information—or when different features are better described by different similarity functions.

FATK was built around two questions: which features matter? and what kind of similarity should each feature use? Instead of fixing one global kernel in advance, the model learns feature relevance and kernel structure jointly.

Core idea

For each feature k, FATK constructs a local kernel as a learned mixture of linear, RBF, and polynomial components. A separate learned weight controls how much that feature contributes to the final kernel. This gives two levels of adaptivity: feature relevance through δk, and feature-specific kernel preference through αk, βk, and ζk.

Learning the kernel

The kernel parameters are optimized using Centered Kernel Alignment (CKA), encouraging the learned kernel matrix to align with the label structure. Once learned, the kernel can be used by conventional kernel classifiers such as Kernel Ridge Regression and Support Vector Machines.

This separation is useful conceptually: FATK learns the geometry of similarity, while a standard kernel classifier performs the final prediction.

Experimental questions

The evaluation was designed to test more than predictive accuracy. We asked whether FATK can recover the truly informative features on controlled synthetic data, whether it remains robust as irrelevant dimensions are added, and where the feature-wise additive construction breaks down.

Sparse feature recovery

A particularly useful stress test contains only three informative features among thirty-three total dimensions. Because the data-generating process is known, we can directly compare the learned feature weights with the true signal features.

ModTriple reached 76.8% KRR accuracy, 79.2% SVM accuracy, and an msignal score of 0.985 at SNR 1.5. The feature-relevance profile shows the learned weights concentrating on the informative dimensions while suppressing the noise features.

Noise robustness

We also varied the amount of irrelevant information and the signal-to-noise ratio. The goal was to test whether feature-wise weighting could preserve predictive performance while still concentrating mass on useful features.

Where FATK works — and where it fails

FATK’s feature-wise additive construction is also its main inductive bias. It performs strongly when useful information can be attributed to individual dimensions, but it struggles when prediction depends primarily on interactions between features.

On the additive synthetic task, ModTriple achieved 92.1% KRR and 93.9% SVM accuracy. On product and XOR interaction tasks, performance dropped to approximately chance level.

Main findings

Feature selection. FATK learns relevance weights that concentrate on informative dimensions rather than treating all variables equally.

Adaptive similarity. Each feature can learn a different mixture of linear, RBF, and polynomial behavior instead of sharing one global kernel family.

Noise robustness. Feature-wise weighting helps suppress irrelevant dimensions in controlled synthetic settings.

A clear inductive bias. The same additive decomposition that makes feature relevance interpretable limits the model when predictive structure depends on strong cross-feature interactions.

Limitations

Interaction modeling. Product and XOR experiments reveal that the current formulation does not naturally capture strong cross-feature interactions.

Computational cost. FATK learns more parameters than classical global kernels and therefore incurs additional optimization cost.

Classification only. The current study focuses on classification; regression remains an extension rather than an evaluated result.

What I would explore next

The part of this project I find most interesting is the tension between interpretability and expressiveness. Decomposing the kernel feature by feature makes learned relevance directly inspectable, but the same decomposition becomes restrictive when useful structure lives in interactions between variables.

A natural next step would be to preserve feature-level interpretability while introducing selective pairwise or higher-order interactions, rather than reverting to a completely global kernel. Other directions include sparse interaction learning, cheaper parameterizations, regression, and stability analysis of the learned relevance weights.
