Differential Attention Transplant for Pretrained CLIP

Can differential attention be surgically inserted into an already pretrained CLIP vision encoder without destroying the representation geometry that pretraining created?

Research proposal · Theoretical work · 2026

This proposal studies differential attention as a transplant problem, not as a full retraining problem. The goal is to modify selected self-attention blocks in a pretrained CLIP image encoder while preserving the original model as closely as possible at initialization, then adapt only a small new parameter subset with a low-budget calibration stage.

The motivation is practical: standard attention may not be ideal when we want stronger distractor suppression, nuisance robustness, or more selective token mixing, but CLIP already contains a valuable image-text embedding geometry that we do not want to overwrite. The central question is therefore how much architectural change can be introduced while keeping the pretrained teacher behavior under explicit control.

1. From standard attention to differential attention

For one attention head, the pretrained teacher uses the standard form

Yt = AtV.

The converted student introduces two attention branches and computes

Ys = (A1 − λA2)V,

or, in the centered version proposed here,

Ysctr = [A1 − λ(A2 − UT)]V.

Branch 1 is the teacher-preserving route. Branch 2 is intended to learn a complementary subtractive correction. The coefficient λ controls how strongly that second branch can alter the original token-mixing behavior.

2. Why λ is a safety parameter

Both A1 and A2 are row-wise softmax matrices, so each row sums to one. In the uncentered differential form,

(A1 − λA2)1 = (1 − λ)1.

This means subtraction changes not only where attention is placed, but also the total mixing mass of the operator. The proposal therefore bounds the subtraction coefficient by construction:

0 ≤ λℓ,h ≤ λmax < 1.

A sigmoid parameterization lets optimization operate over unconstrained variables while guaranteeing that the effective subtraction strength remains inside the admissible interval.

3. Why centering matters

A subtle issue appears when Branch 2 is initialized with small logits. Softmax does not map near-zero logits to a near-zero attention map; it maps them to an approximately uniform distribution. So a branch that is intended to be almost inactive can still subtract a non-trivial uniform component from every token position.

Centering removes that artifact by subtracting only the deviation of Branch 2 from the uniform baseline. If A2 ≈ UT, then A2 − UT ≈ 0, and the correction is correspondingly small.

4. Teacher-preserving initialization

The transplant is deliberately asymmetric. Branch 1 copies the original teacher projections exactly, so its initial attention map matches the pretrained teacher. Branch 2 should not duplicate that same dominant structure; it is initialized as a small teacher-informed residual pathway.

For each head, the teacher query and key projection matrices are decomposed with SVD. The dominant singular directions remain represented in the full teacher copy, while the low-energy spectral tail is used as a structured template for the new Branch-2 query and key projections.

Those residual matrices are normalized and rescaled to a small fraction of the corresponding teacher norm. The intention is to give Branch 2 useful structure without allowing it to compete with the teacher route at step 0.

5. Step-0 drift

The proposal makes the initial teacher-student mismatch explicit. For one head,

Ys − Yt = (A1 − At)V − λA2V.

Under the exact-copy initialization of Branch 1, A1 = At, so the first term vanishes and

Ys − Yt = −λA2V.

This is the core step-0 result: once the teacher path is copied exactly, initial deviation is driven by the subtractive branch, making λ the most direct control over transplant risk.

6. How local drift propagates through CLIP

A local mismatch does not remain local. Once the modified hidden state enters later residual blocks, the perturbation can propagate and potentially amplify. With a local Lipschitz assumption and a bounded teacher-student block mismatch, the proposal derives the recurrence

||δℓ+1||F ≤ (1 + Lℓ)||δℓ||F + εℓ.

This gives a concrete reason to begin with late-layer-only transplantation: a mismatch introduced late in the vision stack has fewer subsequent layers through which it can accumulate.

7. From representation drift to CLIP logit drift

Because CLIP uses normalized image and text embeddings, teacher-student cosine preservation directly controls the change in image-text similarity scores. The proposal derives

|ΔSij| ≤ s √(2 − 2〈ũi, ui〉).

The practical implication is important: feature matching is not merely an auxiliary representation loss. Keeping teacher and student image embeddings close in cosine similarity directly limits worst-case CLIP score drift.

8. A data-informed initialization for λ

Instead of choosing every headwise subtraction strength arbitrarily, the proposal also considers a closed-form prefit on a small calibration set. Treating the Branch-2 head contributions as fixed regressors leads to a ridge-regression problem,

λ* = (BTB + εI)−1BT(u − yt),

after which each coefficient is projected back into the safe interval [0, λmax]. This provides a teacher-informed step-0 initialization before gradient-based calibration begins.

9. Low-budget calibration

The intended operating regime is deliberately small: keep most pretrained CLIP weights frozen and train primarily the new Branch-2 query/key parameters and the bounded subtraction coefficients, with optional late-layer adaptation only if necessary.

The calibration objective combines several terms, each targeting a different failure mode:

Teacher logit distillation preserves the teacher's bidirectional image-text retrieval geometry.

Feature matching limits image-embedding drift.

Student CLIP loss keeps the student responsive to paired image-text supervision.

λ regularization discourages unnecessary subtraction.

Nuisance consistency encourages robustness under occlusion, crop shift, clutter, background changes, or mild corruption.

Branch diversity discourages Branch 2 from simply collapsing into Branch 1.

10. Experimental plan

This is currently a theoretical proposal and implementation blueprint, not a completed benchmark result. The proposed calibration set mixes clean image-text pairs, nuisance-augmented pairs, and hard negatives. Clean pairs expose regressions, nuisance-augmented pairs create conditions where suppressive attention may help, and hard negatives prevent robustness from being achieved by simply becoming less discriminative.

The main acceptance criteria are intentionally strict: minimal regression immediately after conversion, high teacher-student embedding similarity, low similarity-logit drift, recovery of baseline zero-shot behavior after calibration, and improvement on at least one robustness or retrieval metric without allowing Branch 2 to dominate the teacher path.

11. Ablations I would want before claiming success

A convincing experiment should separate the value of the transplant from the value of generic parameter-efficient tuning. Important comparisons include λ-only training, a generic low-rank adapter baseline, late-layer-only versus broader conversion, random or zero Branch-2 initialization, removal of nuisance consistency, and removal of the branch-diversity term.

These controls are essential because the central claim is not simply that a modified CLIP can be fine-tuned. The more specific claim is that differential attention can be introduced as a controlled structural intervention while preserving pretrained geometry and using only a modest adaptation budget.

Current status

The current work covers the theoretical construction, step-0 safety analysis, transplant initialization, calibration objective, efficiency considerations, and experimental design. The next step is empirical validation: implementing the transplant in pretrained CLIP checkpoints and testing whether the predicted preservation/robustness tradeoff appears in practice.
